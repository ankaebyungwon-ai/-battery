# RE:CELL 14 메인 홈 — 배터리팩 분해도

전기차 배터리팩을 층층이 띄운 **분해도(exploded view)** 를 첫 화면에 두고,
좌우 설명 상자와 지시선으로 부품 11개를 설명하는 메인 홈입니다.
그 아래에 재활용 8단계, 처리 경로 3갈래, 14개 주제, 실험실, 출처가 이어집니다.

빌드 도구 없이 HTML · CSS · 일반 `<script>` 만 씁니다.
`index.html` 을 더블클릭해도(file://) 그대로 열립니다.

## 파일 구조

```
home-exploded/
├── index.html        화면 뼈대 (섹션 6개, 내용은 대부분 JS가 채움)
├── css/
│   └── style.css     색 · 글꼴 · 배치. 맨 위 목차대로 1~9번 구역
├── data/
│   └── parts.js      ★ 부품 11개 설명과 해체 순서 8단계 — 글만 고칠 땐 여기만
└── js/
    ├── iso.js        등각 투영 그리기 도구 (box, face, line)
    ├── exploded.js   분해도 그리기 · 설명 상자 배치 · 해체 순서 재생
    └── home.js       메뉴, 재활용 8단계, 처리 경로, 14개 주제
```

`index.html` 맨 아래에서 스크립트를 **iso → parts → exploded → home** 순서로 불러옵니다.
앞의 파일이 만든 `window.ISO`, `window.PARTS`, `window.DISASSEMBLY` 를 뒤 파일이 쓰기 때문에 순서를 바꾸면 안 됩니다.

## 분해도는 어떻게 그려지나

### 1. 3D 좌표 → 화면 좌표 (`js/iso.js`)

팩을 `x`(가로) · `y`(세로) · `z`(높이) 좌표로 생각하고, 30° 등각 투영으로 화면에 옮깁니다.

```js
화면 x = (x - y) × cos30°
화면 y = (x + y) ÷ 2 - z
```

`box(x, y, z, 너비, 깊이, 높이, [윗면색, 왼쪽면색, 오른쪽면색])` 하나로 직육면체를 그립니다.
빛이 왼쪽 위에서 온다고 보고 윗면을 가장 밝게, 오른쪽 면을 가장 어둡게 칠합니다.

### 2. 층을 띄우기 (`js/exploded.js` 의 `LAYERS`)

조립된 팩에서는 붙어 있는 부품들을 `z` 값만 크게 벌려서 그리면 분해도가 됩니다.

| 층 | z (높이) | 내용 |
|---|---|---|
| housing | 0–45 | 외부 하우징, 안쪽 리브 |
| cooling | 85 | 냉각판과 냉각수 통로 |
| tray | 150–186 | 트레이, 격자 벽, 열전도 패드(분홍) |
| modules | 235–283 | 모듈 2줄 × 7개 |
| mmc | 300 | 모듈 관리 장치 |
| busbar | 345 | 구리 버스바, 고전압 고리(주황) |
| cables | 390 | 저전압 · 고전압 케이블 |
| bmc | 430 | 팩 제어기 |
| cover | 495–524 | 커버와 둘레 나사 |
| switch | 585 | 스위치 박스 |

아래층부터 그려야 위층이 아래층을 가립니다 (`ORDER` 배열).

### 3. 설명 상자와 지시선 (`layout()`)

1. 부품마다 `at: [x, y, z]` 로 정한 점을 화면 좌표로 바꿔 번호 표지를 찍습니다.
2. 설명 상자의 **실제 높이를 재서**, 같은 쪽 상자끼리 겹치지 않게 아래로 밀고, 바닥을 넘으면 다시 위로 밉니다.
3. 상자가 그림보다 길게 쌓이면 그림 위아래 여백을 늘립니다.
4. 상자 → 꺾인 선 → 번호 표지 순서로 지시선을 긋습니다.

창 크기가 바뀌거나 글꼴이 늦게 로드되면 다시 배치합니다.
**1000px 미만**에서는 지시선을 숨기고, 조작부를 그림 바로 아래로 올리고, 설명 상자는 그 아래 목록이 됩니다.

### 4. 강조와 해체 순서

- 설명 상자나 번호를 누르면 그 층만 밝아지고 나머지는 흐려집니다.
- **해체 순서 재생**은 `DISASSEMBLY` 8단계를 2.8초마다 넘깁니다. 이미 떼어 낸 층은 거의 투명하게(`.gone`) 남깁니다.
- 운영체제에서 '움직임 줄이기'를 켜 두면 자동 재생 없이 한 단계씩만 넘어갑니다.

## 자주 고칠 곳

| 하고 싶은 것 | 고칠 곳 |
|---|---|
| 부품 설명 문구 | `data/parts.js` 의 `desc`, `cut` |
| 해체 단계 문구 | `data/parts.js` 의 `DISASSEMBLY` |
| 번호 표지 위치 | `data/parts.js` 의 `at` (3D 좌표) |
| 설명 상자를 반대쪽으로 | `data/parts.js` 의 `side: 'L'` ↔ `'R'` |
| 모듈 개수 | `js/exploded.js` → `LAYERS.modules` 의 반복 횟수 |
| 부품 색 | `js/exploded.js` 맨 위 `C` |
| 재활용 8단계 · 처리 경로 · 주제 | `js/home.js` 의 `STEPS`, `ROUTES`, `GROUPS` |
| 출처 목록 | `index.html` 의 `#sources` |
